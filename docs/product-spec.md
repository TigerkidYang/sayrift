# 产品规格：要复刻的 Typeless 行为

> 状态说明（2026-10-06）：Sayrift v0.2.1 已正式发布 Windows 安装包和 Android APK，见 [发布说明](release-notes.md)。本文的 Typeless 调研依据为 2026-09-23 快照，未重新核对竞品最新版本；早期里程碑和实现标记不代替当前发布功能与验收记录。

> 2026-10-08 更新：v0.2.2 将下方本机 Typeless 2.8.1 对照后的共享 prompt 整合进两平台安装包，见[新版核验](release-0.2.2.md)。其余竞品行为条目仍保留原调研日期。

> 依据：2026-09-23 对 Typeless 官方文档、发布说明（调研时 v2.8.0）、定价页存档和用户评测的调研。来源编号见文末。
> 标注 (U) 的是未能从一手来源确认的内容。
> 优先级：**P0** = 核心体验，**P1** = 用起来顺手，**P2** = 锦上添花，**P3** = 暂不做。当前实现与发布范围见 README 和 docs/release-notes.md。
> **官方全部功能的逐项清单和我们的实现状态在 `docs/typeless-features.md`**；本文件只写行为规格和取舍。

## 0. 为什么做

Typeless 免费额度原来是每周 8000 词。价格页的横幅文案写着 “Sep 22 起 Free 改为 2,000 词/周”，用户在 09-16 左右已经看到消息 [27][28]。Pro 是 $12/月（年付）或 $30/月（月付）[22]。
用户每周用量 < 8000 字。本项目用 OpenRouter 上的 ASR + LLM 在本地复刻，目标成本 < $1/月（见 docs/models.md）。

## 1. 三种模式与热键（Windows）

| 动作 | Typeless 默认 | 我们的默认 | 优先级 |
|---|---|---|---|
| 听写 Dictate | 右 Alt | **右 Alt** | P0 |
| 翻译 Translate | 右 Alt + 右 Shift | **右 Alt + 右 Shift** | P1 |
| 问答 / 语音编辑 Ask anything | 右 Alt + 空格 | **右 Alt + 空格** | P1 |
| 结束任意模式 | 再按一次主键（右 Alt），或点 Voice bar 上的 ✓ | 同左 | P0 |
| 取消 | 现行文档：Voice bar 上的 ×；旧文档：Esc（取消插入，但转写结果仍进历史）[9] | **两者都有**：Esc 和 × | P0 |
| 重新粘贴上一次结果 | 官方没有（Wispr Flow 有：Alt+Shift+Z）[46] | 不做热键；托盘里的“最近结果”可点击复制（官方对应的是历史记录） | P2 |

交互细节：
- **点按 / 按住两种都支持**：
  - 快速点按一下：进入“免提”录音，再点一下主键结束。这是**现行官方文档**描述的切换式 [1][12]。
  - 按住超过 0.5 s 再松开：松开即结束（push-to-talk）。**旧文档**（≤0.9.0）是这样写的，现行文档没说是否仍然有效 (U)。
    因为只有好处、没有冲突，所以保留。`[hotkeys] hold_to_talk = false` 可以改成严格的切换式。
- 热键全部可改，并支持给一个动作绑定多个键 [4]。只按修饰键的组合（右 Alt、Ctrl+Win）必须支持，因为有 Typeless Windows 用户在用 Ctrl+Win [40][41]。鼠标侧键是 P2。
- 右 Alt 的坑：
  - 单独点一下 Alt 会激活很多程序的菜单栏或 Ribbon 快捷提示，所以被我们用作热键时要吞掉。
  - 按住右 Alt 时如果按了不属于我们组合的键（比如 Tab），要把 Alt 补发出去再放行，别破坏系统快捷键。
  - AltGr 键盘布局下，右 Alt 会伴随一个假的左 Ctrl。
  - 在中文输入法（微软拼音、搜狗等）里，单独按 Shift 会切换中英文。所以翻译组合键里的右 Shift 被我们用掉时也必须吞掉，否则每次翻译都会顺带切换输入法状态。
- 麦克风在按键**按下的瞬间**打开 [13]。开头的字不能丢。
- 开始和结束有提示音，可关闭 [4]（P1）。录音时静音其他音频 [4]（P3）。

## 2. 听写（Dictate）— P0

流程：按热键 → 浮层出现、开始录音 → 说话 → 结束 → 上传 → ASR → LLM 整理 → **插入到开始听写时的光标处** [1]。不做流式上屏 [36]。

**自动整理规则**（Typeless 官方宣称 [21][52][12]，以及它的示例 [10]）：
- 去掉语气词和口癖（um / uh / you know；嗯 / 啊 / 额 / 那个 [34]）、重复词、说错重来的部分。
- **自我修正只保留最终版本**：“明早 9 点……不对，下午 3 点”只留下午 3 点 [34][35]；“7 am? Oh, actually … 3 pm”变成 “3 PM” [10]。
- 口述的清单、步骤、要点整理成列表 [21]。示例：一句话报了三样要买的东西，输出成一行标题 + 每项一行的列表 [10]。
- 邮件形态的口述（称呼、正文、落款）分行排版；电话号码规范化，如 (408)123-4567 [10]。
- 按当前输入框调整格式和语气：工作邮件、聊天、客服回复不一样 [52]。
- v2.0 起还会 [12]：把插入语当作背景信息而不写进正文；对说不出名字但描述了的东西补上名字（不许编造）；把乱序的内容按重要性重排；说话中途改主意时只保留最终决定。**这几条改写幅度大，我们放在 P2，默认关闭，先保证“忠实”。**
- **问句照原样写出来，绝不回答** [10]。官方新手引导专门测试这一点：一句耳语提问“橙汁多少钱”，输出必须还是这句问题。
- 用户曾抱怨过度改写、丢内容 (U)，以及中文同音词错误（折扣听成进口）[37]。**因此我们的原则是：宁可少改，不可丢信息、不可编造。**

我们的实现：`src/local_typeless/prompts/dictation.md`；回归测试：`evals/polish/cases.jsonl`。

### 2026-10-08 本机 Typeless 2.8.1 对照补充

本轮按用户历史中的短指令、产品逻辑解释和多层选项构造虚构输入，实际回放 8 条音频；方法与结果见 [历史场景对照](typeless-history-comparison-2026-10-08.md)。这是该版本在本机的有限样本观察，不代表官方对所有输入的保证。

- 长解释按语义作用分段：背景/定义、展开的例子、返回整体目标。短句和叙事不机械拆分。
- 相互排斥的操作选项可以整理成编号列表；每个分支的条件、例外和后果仍属于该分支。普通连续条件句保留为正文。
- 明确口述的子层选项用 `(a)/(b)/(c)`；普通几个名词连说不必拆成子列表。沿用口述的主题标签，不另造摘要标题。
- 允许为明确口述的消息或直接引语加引号；不是给整个听写结果套引号。
- 官方本轮有将 `PR` 误识别成 `P2`、省略一条结尾限制的情况。取舍仍遵守不编造、不丢信息：学习排版，保留原始技术标识和未定约束，不复制这些错误。

以上为源码 prompt 的行为更新；v0.2.1 下载包不会因源码更新自动获得这些变化。

其他：
- 单次最长 **9 分钟**；8:00 开始在浮层上倒计时 60 秒；到上限时自动结束，已录内容照常处理并存入历史 [7]（P1）。
- 没有聚焦输入框时：弹出结果卡片，带“复制”按钮 [19]（P1）。粘贴失败时（例如提权窗口）也走这条路。
- 需要联网，不支持离线 [31]。

## 3. 翻译（Translate）— P1

- 按翻译热键，用任意语言说，结束后把**译文**插入光标处；不流式 [2][17]。
- 目标语言是一个**有序列表**（设置里添加、拖动排序），浮层上方显示当前目标语言，悬停可切换 [2][17]。
  我们的 v1：配置文件和托盘菜单里切换；浮层悬停切换放到 P2。
- 译文要像母语者写的，保留语气和能量，并适配用途（消息、邮件、帖子）[2][12]。
- 同样做听写的整理（去语气词、应用自我修正），然后翻译。

## 4. 问答 / 语音编辑（Ask anything）— P1

按 Ask 热键 → 说 → 结束。按上下文分流 [3][18]：

| 上下文 | 行为 | 优先级 |
|---|---|---|
| 可编辑区域里有选中文字 + 一句指令（“改正式一点”“翻成日语”“缩短”） | **直接替换选中内容** | P1 |
| 没有选中 + 写作请求（“帮我写一封邮件给 Emma……”，即 Help me write） | 生成完整草稿，插入光标处 | P1 |
| 没有选中 + 提问 | 在**结果卡片**里显示答案（可复制） | P1 |
| 只读内容里有选中文字 + 提问（“这段是什么意思”） | 结果卡片显示答案，不动原文 | P2 |
| 需要最新信息（“搜索”“最新”“现在”） | 联网搜索后回答（OpenRouter web 插件） | P2 |
| 动作类（“打开 B 站搜 xxx”） | 打开对应网站并带上搜索词 | P3 |

- 上下文主要就是选中的文字；官方隐私政策提到会处理“相关文本”，但不存“屏幕上下文” [29]。读全屏未有文档 [33]。
- 例子 [14]：把一句话的备注扩成正式邮件 → 再改友好点 → 再翻成日语；把文章总结成三点；修语法；改长短；换语气；找行动项；起草回复；调试代码。

## 5. 个性化

| 功能 | Typeless | 我们 | 优先级 |
|---|---|---|---|
| 个人词典 | 手动添加、CSV 导入、在用户修改后自动加入 [5][12] | 配置文件手动维护：作为 gpt-transcribe 的 keywords + LLM 术语表。CSV 导入和 UI 编辑 P2；自动学习 P3 | P1 |
| 按应用调整语气 | 自动；没有按应用的风格选择器 [43][52] | 进程名/标题 → 应用类别 → 该类别的风格说明（内置默认 + 用户可写） | P1 |
| 写作风格学习 | 自动学习正式/随意、简洁/详细，可关闭 [6] | 以后做：从历史里总结风格档案 | P3 |
| 语言 | 100+ 种，自动识别，可混说；中文有简体、台湾繁体、香港繁体 [1][21][45] | 默认简体中文 + 英文混说；gpt-transcribe `languages=["zh-cn","en"]`；输出简繁可配置（LLM + 可选 OpenCC 兜底） | P0 |

## 6. 历史、统计、设置

- **历史**（本地）[5]：按全部 / 听写 / Ask 筛选；复制、用原音频重试、下载原音频、删除；保留期限：永久 / 1 年 / 1 月 / 1 周 / 24 小时 / 不保存。
  我们：SQLite 存原始转写、最终文本、模式、应用、各阶段耗时、费用；音频默认不存（开关打开后才存，便于重试和评测）（P1/P2）。
- **统计** [12][21][43]：累计字数、平均语速（WPM）、节省的时间（相对打字 45 wpm）、连续使用天数。我们额外统计**实际花费**（P2）。
- **设置** [4]：热键、麦克风（自动 / 指定设备 + 音量条）、提示音、开机自启、主题。我们 v1 用 TOML 配置文件，GUI 设置页 P2。
- 隐私 [21][29]：Typeless 宣称云端不留存、不用于训练、历史存在本地。我们对应：OpenRouter `data_collection=deny`（可选 `zdr`）、本地存储、API key 只来自环境变量。

## 7. 浮层（Voice bar）

- 状态 [9][13][7][20]：录音中（跳动的音量条）→ 处理中（进度 / 动画）→ 完成；错误如“麦克风不可用”、服务繁忙；
  翻译模式在上方显示目标语言；接近时长上限时显示倒计时。
- 布局（官方截图）：**× 取消 · 波形 · 计时器 · ✓ 完成**。计时器显示已录时长；最后 60 s 变成红色倒计时。
  处理中只保留 ×（可取消），不显示 ✓。
- 始终置顶、**绝不抢焦点**：按钮可以点，但点了也不激活窗口（WS_EX_NOACTIVATE，`tools/ui_smoke.py` 用真实鼠标点击验证过）。
  位置在屏幕底部居中（官方没有写明具体尺寸和位置）。
- 翻译目标语言的悬停切换还没做，目前在托盘菜单里切换。

## 8. 延迟

Typeless 不流式：停止后上传，第三方测得约 1–3 s，长段落约 5 s [36][37]。
**我们的目标：10 s 左右的语音 p50 ≤ 1.5 s；当前实测约 1.6 s**（docs/models.md §4）。

## 9. 与 Wispr Flow 的差异（参考）

- Wispr：Windows 上默认按住 Ctrl+Win；双击进入免提；Ctrl+Win+Alt 进入命令模式（需要选中文字）；有 Snippets（语音触发的文本片段）；有按应用类别选的 Styles，但只改大小写和标点；有“粘贴上一次结果” [46–50]。
- Typeless 改写得更重，并且多了翻译和助手能力。**我们以 Typeless 为准**：Wispr 的“粘贴上一次结果”不做热键（托盘最近结果代替），Snippets 放在 P3。
