# Typeless v2.8.1 本机对照（2026-10-08）

本次实际操作官方 Typeless Windows v2.8.1，取得四条合成语音的听写结果，再用相同音频运行 Sayrift。它不同于[此前仅针对 Sayrift 的提示词评测](prompt-quality-2026-10-08.md)，不能把此前本地历史分析或 OpenRouter 调用称作官方产品对照。

## 方法和边界

- 官方账号 Free，已达到周额度。实际提示为“Typeless 现在会变慢”，仍可完成转写，不能仅凭额度提示判断不可用。
- 前期外放拾音失败的无声、取消记录不计入有效样本。随后临时启用已有的 Realtek 立体声混音，选择为 Typeless 输入，关闭“语音输入时静音”，直接播放测试音频。没有安装虚拟声卡或更改系统默认麦克风。
- 结束后恢复 Typeless 自动检测麦克风、开启录音时静音、停用立体声混音，并恢复内存中备份的剪贴板。
- 三条短音频来自本地旧研发库的合成样本；长音频用公开虚构用例 `zh_long_informal_points` 经 Edge TTS 生成，83.328 秒，16 kHz 单声道 OGG/Opus。音频与个人历史不提交。
- 官方输出从历史界面读取，摘要会压平换行，因此核对内容和编号，不把摘要空格当成最终换行。请求有额度限速，且历史页需重新进入刷新，不报告官方精确延迟。
- Sayrift 基线为 `0d26b34`，用 `sayrift file … --app Typeless.exe`，实际使用 `openai/gpt-transcribe` 和 `deepseek/deepseek-v4.1-flash`。这是音频到文本的对照，不是光标插入或 Android 真机验收。

长样本官方开头：

官方保留“普通人能不能查到、能不能拿来用”“具体的使用条件”“学生和老师”“先不做付费功能”“每个月更新两次”“限制在一个城市”“我只是想先评估，不是让你现在开始开发”。

仍有差异：官方会补“市场需求”这样的概括标签，把一个限制放入括号，并进一步压缩口语连接词。本轮沿用 Sayrift 已有的不新增标题、不改变动作含义的保守约束，不宣称四条样本证明整体质量相当。

## 提示词修正

先增加 `zh_long_choice_action` 用例，再修改共享听写提示词：明确重启命名时只保留具体名称；保留执行者与动作动词，选择不能改成给出、填写或生成；用不同领域的排班示例演示两者同时成立。还为备用模型已有的英文购物清单格式不稳定问题补充英文记事本示例。

同一长音频复测后，Sayrift 已输出“我想做一个资料整理工具”，保留“让它选择为什么这些说法对不上的理由”、三项评估与结尾限制。ASR 将“他”识别为“它”的差异仍在，未宣称提示词能消除中文同音代词歧义。
