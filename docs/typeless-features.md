## 13. 账户、套餐、额度、推荐（全部 ➖ 不适用）

- **Free**：“每周有限字数”、标准准确率、高峰期标准访问。包含听写 / 翻译 / Ask / 个性化 / 词典 / 100+ 语言 / 按应用语气 / Whisper mode / 四端。

## 各来源之间的冲突，以及我们的取舍

| 冲突 | 取舍 |
|---|---|
| 免费额度 8,000 vs 2,000 词/周 | 与本项目无关（这正是做它的原因） |

| 语言数 100+ vs 120+ | 无关 |
| HIPAA 的不同说法、“本地” vs 云端处理 | 无关；我们的隐私做法见 §15 |
